# Player Images Directory

This directory will contain player images. 

## Image Guidelines:
- Format: PNG or JPG
- Size: 150x150px recommended
- Naming: Use player ID or name (e.g., neymar.png, mitrovic.jpg)

## Default Image:
A default player silhouette image will be used when specific player images are not available.

You can add actual player images here later to replace the default placeholder.
